## Solution

### 1. Define initial conditions

First, we start by defining the initial conditions in a keyword struct, with all dimensional inputs reported in SI units. This includes parameters for geometry (`L`, `H`, `W`), flow rate (`Q`), fluid (medium) properties (`μ`, `ρ`, `D`), inlet O₂ (`c_in`), and kinetics (`q_max`, `K_m`). The default parameters describe a 10 mm × 0.5 mm × 5 mm chamber perfused with culture medium at 10 µL/min over a dense monolayer. The uptake parameters are order-of-magnitude estimates (~1e-16 mol/cell/s × ~2e9 cells/m²).

```julia title="Defining initial conditions"
Base.@kwdef struct ChamberParams
    L::Float64 = 10e-3        # chamber length [m]
    H::Float64 = 0.5e-3       # chamber height [m]
    W::Float64 = 5e-3         # chamber width, out of plane [m] (converts Q to mean velocity)
    Q::Float64 = 10e-9 / 60   # volumetric flow rate [m³/s] (10 µL/min)
    μ::Float64 = 0.78e-3      # medium viscosity at 37 °C [Pa·s]
    ρ::Float64 = 1000.0       # medium density [kg/m³]
    D::Float64 = 3.0e-9       # O₂ diffusivity in medium at 37 °C [m²/s]
    c_in::Float64 = 0.2       # inlet O₂, air-saturated medium at 37 °C [mol/m³ = mM]
    q_max::Float64 = 2e-7     # max areal O₂ uptake of the monolayer [mol/m²/s]
    K_m::Float64 = 5e-3       # Michaelis–Menten constant for O₂ [mol/m³] (~5 µM)
end
```

### 2. Compute dimensionless forms

The next step is to convert the input parameters to dimensionless forms to aid computation. Without this step, combining numerical values of different magnitudes into a single matrix can cause a loss of precision. This also promotes better conceptual understanding, as solutions involving the same Reynold's number (`Re`), `Pe`, `Da`, `κ`, and `ℓ` behave in an identical manner regardless of actual values.

```julia title="Convert input parameters to dimensionless form"
function groups(p::ChamberParams)
    U = p.Q / (p.W * p.H)
    (U=U, ℓ=p.L / p.H, Re=p.ρ * U * p.H / p.μ, Pe=U * p.H / p.D,
     Da=p.q_max * p.H / (p.D * p.c_in), κ=p.K_m / p.c_in)
end
```

As shown above, `groups` returns a `NamedTuple`, which acts as an immutable record of data with named property (attribute) access using familiar dot notation, e.g., `g.Re`. Below, `print_groups` renders chamber parameters, `p`, in a human-readable format and performs validation on the primary base assumption, namely that $Re << 1$, the domain where Stokes flow applies.

```julia title="Display group attributes and validate base assumptions"
function print_groups(p::ChamberParams)
    g = groups(p)
    @printf("Q = %.3g µL/min   U = %.3g mm/s\n", p.Q * 60e9, g.U * 1e3)
    @printf("Re = %.3g   Pe = %.3g   Da = %.3g   κ = %.3g   L/H = %.3g\n",
            g.Re, g.Pe, g.Da, g.κ, g.ℓ)
    g.Re > 0.1 && @warn "Re = $(round(g.Re, sigdigits=3)): inertia is not negligible, " *
                        "Stokes results become approximate (switch to Navier–Stokes)."
    return g
end
```

### 2. Meshing

One of the most important steps in 3D computational analysis is meshing, which breaks a continuous space into a discrete domain that can be solved in finite time. Mesh quality and density have large impacts on solution accuracy and computation time, often antagonistically. For instance, a highly dense mesh can dramatically increase computation time, but a coarse mesh may oversimplify results, especially for complex flow geometries. In research and engineering applications, a hybrid approach is frequently used to reduce compromises, i.e., mesh density is adjusted to be finer at geometric areas of interest, such as corners.

First, to define our mesh, we create another struct of `MeshParams` to pass to the builder. `MeshParams` also contains a scaling function, `ceiling`, which defines the dimensionless (normalized) ceiling height $h(x)/H$ as a function of the dimensionless axial coordinate $x$, `x -> 1.0`.

<!--Mesh options. `ceiling(x)` is the dimensionless ceiling height h(x)/H as a function of the dimensionless axial coordinate; it must equal 1 at the inlet so the parabolic inlet profile is correct. `grading > 0` clusters cells toward the floor, where the O₂ and shear boundary layers are.-->

<!--It builds a structured grid of nx × ny quadrilaterals on the dimensionless chamber, which spans [0, ℓ] in x and [0, 1] in y.-->

```julia title="Defining mesh options struct"
Base.@kwdef struct MeshParams
    nx::Int = 200
    ny::Int = 40
    grading::Float64 = 2.0
    ceiling::Function = x -> 1.0
end
```

`walls`
: floor, ceiling, and the four chamber walls ("no-slip" condition)
`floor`
: bottom edge (cellular uptake of O₂)
`inlet`
: left edge (initial velocity condition)
`outlet`
: right edge (free outflow)


```julia title="Building a structured quad mesh of the dimensionless chamber"
function build_model(ℓ::Real, m::MeshParams=MeshParams())
    β = m.grading
    stretch(η) = β == 0 ? η : expm1(β * η) / expm1(β)
    φ(x) = VectorValue(x[1], m.ceiling(x[1]) * stretch(x[2]))
    model = CartesianDiscreteModel((0.0, Float64(ℓ), 0.0, 1.0), (m.nx, m.ny); map=φ)
    # Cartesian 2D entities: vertices 1–4, edges 5 (y=0), 6 (y=1), 7 (x=0), 8 (x=ℓ)
    labels = get_face_labeling(model)
    add_tag_from_tags!(labels, "walls", [1, 2, 3, 4, 5, 6])
    add_tag_from_tags!(labels, "floor", [5])
    add_tag_from_tags!(labels, "inlet", [7])
    add_tag_from_tags!(labels, "outlet", [8])
    return model
end
```



### Solver

```julia
function solve_transport(model, uh, Pe, Da, κ; c0=nothing, supg=true)
    reffe = ReferenceFE(lagrangian, Float64, 1)
    V = TestFESpace(model, reffe; conformity=:H1, dirichlet_tags=["inlet"])
    C = TrialFESpace(V, 1.0)

    Ω = Triangulation(model)
    dΩ = Measure(Ω, 4)
    dΓ = Measure(BoundaryTriangulation(model; tags="floor"), 4)

    β = Pe * uh
    h = CellField(sqrt.(collect(get_cell_measure(Ω))), Ω)
    τ = supg ? ((hk, u) -> supg_tau(hk, u, Pe)) ∘ (h, uh) : CellField(0.0, Ω)

    uptake(c) = mm(c, κ)
    duptake(c) = dmm(c, κ)

    # With Q1 elements on (mapped) rectangles Δc ≡ 0 per cell, so dropping the diffusion
    # term from the SUPG residual keeps the stabilization consistent.
    res(c, w) = ∫(w * (β ⋅ ∇(c)) + ∇(w) ⋅ ∇(c) + τ * (β ⋅ ∇(w)) * (β ⋅ ∇(c)))dΩ +
                ∫(Da * w * (uptake ∘ c))dΓ
    jac(c, dc, w) = ∫(w * (β ⋅ ∇(dc)) + ∇(w) ⋅ ∇(dc) + τ * (β ⋅ ∇(w)) * (β ⋅ ∇(dc)))dΩ +
                    ∫(Da * w * (duptake ∘ c) * dc)dΓ

    op = FEOperator(res, jac, C, V)
    nls = NLSolver(LUSolver(); method=:newton, linesearch=BackTracking(),
                   iterations=50, ftol=1e-10, show_trace=false)
    ch0 = c0 === nothing ? interpolate_everywhere(1.0, C) :
          FEFunction(C, copy(get_free_dof_values(c0)))
    ch, _ = solve!(ch0, FESolver(nls), op)
    return ch
end
```
